# Privacy Policy – Server Flip

_Last updated: 11 August 2026_

Server Flip does not collect, store, transmit, sell or share any user data.

**What the extension accesses.** The extension reads the URL of the active browser tab. This is used solely to determine whether the current page is on one of the two server origins you have configured, so that it can display an environment badge and, when you click the toolbar icon, navigate the tab to the equivalent URL on the other origin. This comparison happens entirely on your device. URLs are never recorded and never leave your browser.

**What the extension stores.** Your two configured server origins are saved using Chrome's built-in `chrome.storage.sync`, which is managed by your browser and your Google account's Chrome sync. This data is not accessible to the developer and is not transmitted to any third party by the extension.

**Network activity.** The extension makes no network requests of any kind. It contains no analytics, telemetry, tracking or remote code.

**Changes.** Any changes to this policy will be published in this repository alongside the corresponding release.

**Contact.** Questions can be raised via the issue tracker of this repository.
